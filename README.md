# iris_svm_modelling
This project implements a supervised machine learning workflow to classify Iris flower species using the classic Iris dataset. The project demonstrates the complete ML pipeline—data preprocessing, visualization, model training, and evaluation—inside a single, clean Jupyter Notebook.
# Dataset
The Iris dataset consists of 150 flower samples, Each sample contains 4 features:
Sepal length
Sepal width
Petal length
Petal width
# Technologies Used
Python 3.10+
Scikit-learn
Pandas, NumPy
Matplotlib, Seaborn
Jupyter Notebook
# Results Summary
The trained models achieve high accuracy (>90%) on the test data.
performance and accuracy reports are included in the notebook for detailed comparison across classifiers.
